How SVD Works

Understanding the mathematics behind image compression.

What is Singular Value Decomposition?

Singular Value Decomposition (SVD) is a mathematical technique used to decompose a matrix into three smaller matrices: U, Σ and Vᵀ.

A = U × Σ × Vᵀ

In image compression, an image is represented as a matrix of pixel values. SVD helps us identify the most important information in that matrix.

Rank-k Approximation

Instead of storing all singular values, we keep only the first k largest singular values and their corresponding vectors.

Ak = Uk × Σk × VTk

Steps Used in This Project

  1. Upload an image.
  2. Convert the image into RGB matrices.
  3. Apply SVD separately to each colour channel.
  4. Keep only the first k singular values.
  5. Reconstruct the image using rank-k approximation.
  6. Compare the original and compressed images.
